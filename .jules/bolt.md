## 2024-06-25 - Avoid array chaining in GC-heavy contexts
**Learning:** `arr.filter(cond).map(fn).join('')` and `arr.map(fn).join('')` create multiple intermediate arrays when rendering large UI elements or doing data processing. Although replacing declarative `.map().join()` with imperative loop strings like `for...of` string concatenation might look faster, on UI-bound datasets it violates the directive to not sacrifice code readability for micro-optimizations. For GC pressure, `arr.filter(cond).some(cond)` allocates an intermediate array and iterates up to N times before short-circuiting, whereas it can be rewritten as `arr.some(x => cond(x) && cond2(x))`. Let's check for `.filter(...).some(...)` chained patterns.
**Action:** Replace `.filter().some()` chains with a single `.some()` call using combined conditions.
